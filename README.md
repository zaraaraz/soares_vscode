# soares_vscode
Soares VSCode Extensions

## Soares Code Helper

Uma extensão que goza contigo enquanto programas:

- `//joke` + Enter: a linha é trocada por uma piada em comentário, com a sintaxe da linguagem
- Escrever `TODO` ou `console.log` dá direito a um comentário sarcástico
- 💥🔥 a explodir enquanto escreves
- 🎉 Confetti quando o ficheiro passa a ter 0 erros
- Gravar com erros, 10 Ctrl+Z seguidos, sexta-feira depois das 16h e 2h sem pausa: todos têm resposta
- Hover: git blame falso, e as funções com mais de 50 linhas levam um comentário extra
Para testar: abre a pasta no VS Code e carrega em F5. Para correr os testes: `npm test`.
