# soares_vscode
Soares VSCode Extensions

## Soares Code Helper

Escreve um comando numa linha sozinha, carrega em Enter, e a linha vira um comentário engraçado, com a sintaxe da linguagem (`//`, `#`, `--`, `<!-- -->`...). Maiúsculas ou minúsculas, tanto faz.

| Comando | O que desenha |
|---|---|
| `//help` | A lista de todos os comandos |
| `//love` | Um coração a dizer SOARES |
| `//soares` | SOARES em letras gigantes |
| `//joke` | Uma piada de programador |
| `//flip` | (╯°□°)╯︵ ┻━┻ |
| `//unflip` | ┬─┬ノ( º _ ºノ) |
| `//shrug` | ¯\\\_(ツ)\_/¯ |
| `//lenny` | ( ͡° ͜ʖ ͡°) |
| `//coffee` | Uma chávena de café |
| `//dragon` | Um dragão: aqui há dragões, não mexer |
| `//cat` | Um gato que fez code review |
| `//rocket` | Um foguetão para o deploy de sexta-feira |
| `//rip` | Uma lápide para o código antigo, com a data de hoje |
| `//dice` | Um dado com um número aleatório |
| `//excuse` | Uma desculpa de programador |
| `//8ball` | A bola mágica responde |
| `//fortune` | Uma frase sábia |
| `//motivation` | Uma frase motivacional (mais ou menos) |
| `//sign` | Feito com ❤ e ☕ por SOARES, com a data de hoje |
| `//hours` | Contador de horas perdidas |
| `//magic` | Não sei porque funciona. Não mexer. |

Para testar: abre a pasta no VS Code e carrega em F5. Para correr os testes: `npm test`.
